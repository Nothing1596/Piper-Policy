# 0.2.1 完整联合包

包含 piper-lab 0.2.1、piperx-middleware 0.5.0，99 个固定依赖 wheel 和两个项目 wheel，Windows x64 / Python 3.12。

## 相比 0.2.0

- 新增 MCP `simulation_observe`：限定 MuJoCo 后端，返回真实 RGB 图像，保存 RGB-D、标定与时间元数据；输出目录不可覆盖。
- 保留模型 API 配置、视频编译/查询/评估、视觉策略与下位 CLI。
- 同包提供完整中文新机器部署向导、配置模板和单图 probe 合成样例。
- 安装器直接安装 0.2.1，不需要额外升级补丁。

## 已有实际任务证据

2026-09-27，在开发主机 MuJoCo seed 200 上，助手通过真实 MCP 看图，分阶段调用十个运动/夹爪作业，将红块放入绿色托盘。抓起后看图，转移遮挡阶段查接触，释放归位后再看图；动作结束后才读取独立物理评分，确认红块 in_tray=true、grasped=false。

这是一个助手看图操作案例，使用静态仿真场景的标定几何，并非通用自主规划成功率、持续目标重定位、真人示范迁移或真机验收。本包不携带该机器的执行 token、私人目录或原始运行记录。

此前合成针对性回归 6/6、冻结对照 64/90、两片 LongVIL 真人语义解析属于各自旧配置与提示版本，不能当新 API 供应商的成绩。真人独立时间标注和六棱柱/玻璃目标技能迁移仍未完成。

## 本次打包验证

准确结果见根目录 `PACKAGE-VALIDATION.json`。它区分全新环境离线安装、模块/wheel 校验、CLI 路由、视频解码、CPU 检测接口、MuJoCo 资产、stdio MCP，以及新 root 的仿真相机测试。相机测试不发送运动；不会在安装时自动复演上述抓放任务。

模型供应商接口已做模拟 HTTP 协议及编译链测试；未用你的云端账户实测。Codex/Claude Code 的命令示例不是“本安装器已为你注册”；按照向导在目标机器明确注册。独立环境测试通过也不代表所有新机器驱动都已兼容。

## 分发内容

提供检测器 ONNX、合成 MP4/JPEG、MuJoCo 资产及依赖；不包含 VLM 权重、模型服务、API key、真实人类视频、硬件令牌或代理客户端。第三方许可和分发条件保留于包内。旧 ZIP 保留，不与本版本混用 wheel。

最终安装验证：新建独立环境直接安装 0.2.1，未做安装后替换；上位测试 287 通过、3 跳过。54 个模块与源码/wheel 一致。新 root 在端口 8819 启动并连接 MuJoCo，真实 MCP 返回 640×480 RGB 图像和深度文件，随后正常断连、关闭；未发送运动指令。
