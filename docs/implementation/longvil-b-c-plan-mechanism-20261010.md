# LongVIL v2：B/C 的 plan 机制核验

本轮只读取完整主实验的原始记录，不运行新的模型实验、不修改冻结提示或评分。范围是108个B/C配对、108份C的工具调用序列，以及结果不同的6个配对案例。依据是逐轮initial.json、events.jsonl、Result.json、final-plan.json和冻结源码；不导出模型私有思考文本。

## 结论

C增加的是显式语义记录与分阶段生成协议，不是三维路径规划器。它可把动作候选、对象关系、时间证据和待决问题写入外部状态，再将状态作为工具结果送回模型。当前运行更多体现为一次语义归纳，较少形成问题驱动的持续取证闭环。效果是正向点估计，不能独立归因于持久化存储，也不能宣称完整watch-plan-observe-skill-execute真机链已有效。

## 处理变量核对

108/108配对的共享提示相同；C只在其后增加Plan persistence部分。108/108物体名单相同，108/108初始化图片的像素哈希、帧ID及时间一致。B可用demo_watch与submit_program，C额外有task_plan，并由前端提供初始任务状态。C的新增说明要求持久化少量问题、带证据写interpretation、删除已澄清的视觉问题、提交前读回状态。

task_plan只校验结构、字段、版本和任务身份并保存数据。不检查视频事实真假、不测量三维坐标、不求解运动、不验证接触。主实验工具白名单没有camera_observe、scene_query或机器人动作工具；提交程序由独立符号评分器评估。

actor不含前端初始化create及runner结束后的get。13/14的同批工具都是由同一个API响应预先生成，不能用工具排列顺序证明write结果影响了同批watch。6轮后续补看仍只是时序证据，不证明它们由plan导致。

全部C的432次API中，145次只调用task_plan，包含重复读取、写入和接口修复；这145次仍累计携带3584次图片输入。C比B总API多166次，而actor补看总数只从368增至382（+3.8%）。因此重复图片输入大幅增加主要包含已有上下文在新增生成阶段的重传，不能解释为获得了同等幅度的新视觉证据。

136次update尝试中128次成功；actor还调用get 45次、create 17次，以及2次缺operation的非法请求。10个plan错误分布于8轮：task_not_found 3次、invalid_request 7次。16轮替换了前端已建立的初始任务。没有将这些错误重跑为有利结果。

最终评分通过不代表问题已消除。runner的plan_persistence_verified只要求已颁发task_id、version>1、非空interpretation；不要求问题清空、计划与最终程序一致或actor实际读回。67轮没有get也会由runner在提交后读取持久化文件；这不是模型利用持久化恢复的证据。

没有主动get不等于模型没有读取状态：每次成功update本身返回完整plan，工具结果会进入下一次API的文本上下文。因此get不是利用显式记录的必要条件；这里区分的是actor实际行为与runner的存储验收。

这些案例把差异主要定位在循环次数、操作顺序、叠放关系、参照对象和输出程序格式，而非关节或笛卡尔路径精度。五次改善中一次涉及B非法程序，四次涉及合法程序的语义错误。抽屉同一视频重复中有一次改善、一次退化。

## 效果与证据边界

B语义一致91/108（84.26%），C95/108（87.96%），净增3.70个百分点。净改善集中4个level3语义任务。预定5000次任务级bootstrap的97.5%区间为[+0.93,+7.41]个百分点；同分布的精确敏感性区间为[0,+8.33]，不宣称稳健显著性。

由此可以报告：显式plan工作流对离线动作语义恢复呈现初步正向结果，提供了可检查的语义中间状态。不能报告：磁盘持久化独立有效、计划驱动取证普遍发生、三维建模提升路径精度、完整真机闭环已验证，或本方法优于GPT-Policy。

## 与文献的关系和研究表述

GPT-Policy在毛巾、笔记本两个任务上，各条件三次试验，人类视频从0/3提升至2/3；它支持示范提供程序性引导的有限实证，不能扩展为普遍证明。该方法本身已含当前观察、历史、工具执行反馈、插值和IK，组合视频与计算执行层并非全新结构。原文同时将理解、动作选择与精确接触、结果验证区分开。[原文4.2、3.3及5节](https://arxiv.org/html/2609.19138)

Harness VLA将解析原语用于定位、自由空间运动和接触前准备，接触复杂阶段交给冻结VLA；解析原语并不独自解决接触。[原文Key Finding 3及Appendix B](https://arxiv.org/html/2607.08448)

我们的可检验主张应是：示范给出候选操作程序及关系约束，显式plan保存会改变动作判断的问题，当前观测和可复用计算工具按问题提供证据，将语义子目标绑定到现场坐标，执行后再检验。语义plan随新证据修订，不能把示范像素直接复制为路径。

下一实验先比较等阶段、等图片、等累计生成预算的“通用复核”与“显式plan”，然后独立验证问题触发三维测量的作用。本轮不修改冻结协议，不加新实验。
