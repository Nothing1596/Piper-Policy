# 远端独立运行仿真实验（2026-10-15）

## 执行位置

排程、模型 CLI、MCP 前端、MuJoCo、日志和评分共同运行在 Windows 主机的 WSL
环境。`host: local` 使用原实验 helper 的直接子进程入口；原 SSH 模式保持兼容。
通过 tmux 脱离发起连接，不依赖 Mac 保持开盖或 SSH 长连接。主机自身的关机、
重启、WSL 关闭或网络异常仍须按中断协议处理。

模型固定 `gemini-4-argon-high`。Linux 和 Mac 的 agy 均为 1.3.5；Linux 软件包
由官方 manifest 的 SHA-512 校验。复用远端 Windows 上已存在、且与本机身份
指纹一致的登录，仅在同一主机内准备 Linux CLI 的私有认证文件；认证文件
不进入实验目录、源码包、日志或发行物。

## 迁移规则

- 原作业完整归档，已结束回合的报告与用量不改写、不重跑。
- 对断线后的最后请求，先从原执行数据库按 request_id 查询结果及完成事件。
  不因本机没有收到响应就重发动作。
- 只有确认原执行器身份不再存活、原端点不响应时，才把残留 runtime 标记
  移入同一 profile 的清理归档；保留原账本、所有者标记、锁文件及日志。
- 原仿真进程已退出且没有完整物理检查点时，录制姿态不构成精确恢复。
  中断回合保留为中断，按操作员选择处理，不能伪造连续执行或恢复后成功。
- 迁移使用独立目录并重写活动输入路径，历史报告原文不改写；重新冻结源码、
  路径映射、模型版本、配置、场景及数据哈希。
- 继续无累计任务时限，保留 80 决策 / 120 工具和原有暂停、用量与失败恢复规则。
- 先验证本地直连的 MCP/相机/退出清理，再启动单进程串行排程；验证 SSH 断开后
  远端进程仍在，不创建监视任务，不静默重启异常任务。

## 调用

新作业配置指定 `host: local`、远端实际 Python 路径和 `agy_executable`；
`remote_root` 指向当前远端作业目录，并先建立部署身份记录。

```sh
python /absolute/job/source/tools/run_argon_video_study.py supervise --job /absolute/job
```

直接子进程只替换传输层，不修改工具 schema、控制器、物理参数、提示、采样或
评分规则。实际完成、模型宣称完成、受控释放及终态稳定仍分开记录。

## 经操作员选择的近似恢复（2026-10-15）

`run_approximate_recovery.py` 是单独实验入口，不是公共机器人恢复工具。
只在新模拟器连接前，由 `approximate_physics_recovery.py` 还原最后一条完整
录制快照中的物体世界姿态、机械臂实测关节和对称夹爪开度。快照与场景哈希
固定，暂只支持世界坐标下的自由物体和静止容器。持物快照还必须有哈希固定、
账本中已成功的最后夹爪目标，作为初始化参考；没有该记录则拒绝恢复持物。
这只初始化控制量，不重发旧抓取请求，不保证原接触力或持物状态延续。

缺失的速度初始化为零，机械臂改为实测姿态保持，夹爪使用实测开度保持或上述
已核实的持物控制目标，接触冷启动，模拟时间重新
从零计。这不是完整物理检查点，不声称轨迹连续或精确复现；原中断回合与
用量保持不变。旧动作只核验，不重放。新 provider 会话读取旧计划假设和已
核实的末次动作结果，随后由新 RGB-D 反馈决定动作；旧观测 ID 和几何不复用。

恢复作业等待主作业结束后串行启动。主作业异常暂停时，恢复也暂停，不竞争
资源或自动绕过检查点。恢复报告单列并排除主对照；若需诊断跨段目标覆盖，
仅在模型结束后合并历史有效搬运与新搬运证据，另存评分，不把姿态初始化算
作模型搬运，也不改原报告或宣称连续任务成功。
