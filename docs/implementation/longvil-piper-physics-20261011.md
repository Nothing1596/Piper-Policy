## 场景与执行边界

独立原生环境位于 `/home/featurize/.local/share/piper-physics-sim-20261011`，本轮冻结工作区位于其 `physics-job-01` 子目录。采用本地磁盘，避开先前共享网络盘上的 RPC 写入阻塞，不覆盖原工作区或全局环境。Python 3.12.14、MuJoCo 3.14.0、Piper CLI 0.7.2.dev4 已实际导入并运行。

场景构造只读取原 LongVIL 资产、物体名单、初始位置和初始抽屉状态，不读取动作答案或目标终态来摆放场景。保持固定的坐标系旋转，对场景整体平移；按不同 URDF 原点约定将碰撞底面落在桌面，保留物体尺寸和相对 XY 布局。机器人层级、惯量、伺服及关节限位保持不变。九个正式场景的物体数为3、3、4、3、5、5、6、4、12，另保留一个不计正式成绩的开发场景。碗和玻璃容器使用明确声明的中空碰撞近似；抽屉是无驱动的被动滑轨，行程规范为0.17米。场景 XML、资产与源代码按哈希核验。

合法 LongVIL 原语经共享硬编码求解器转为正常 Piper MCP 工具。getpos 使用私有模拟器位置 oracle；执行时按新鲜物体姿态重新解析动作意图，不逐字执行任意 Python 或沿用过期位置变量。这是视频程序迁移与接触执行的验证，不是视觉三维定位、自动建模或实物数字孪生的验收。对象依靠摩擦、接触和重力运动；没有物体传送、焊接或磁吸。

运动使用完成后才进入下一步的10毫米 Cartesian 路点，以及关节空间中转。参考姿态检查限位和局部连续性；不声称轨迹经过完整碰撞规划。放置后通过已测量的中转姿态返回初态，避免直接从抽屉附近扫向下一物体。容器候选依据实际轮廓与已占空间选择，允许被容器内其他物体支撑。物理评分仍要求真实接触、稳定、空间包含或支撑，不因为模型声明或关节到位而判成功。
