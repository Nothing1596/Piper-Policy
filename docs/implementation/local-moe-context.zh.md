## 工作上下文与缓存

- 固定 32,768 总上下文，预留 8,192 输出及 1,024 安全裕量，输入上限 23,552。
- 本地服务器 apply-template 含实际工具定义，再用同一模型 tokenize；每幅
  原图另保守预留 1,536。不靠字符数估算、不缩小图像或改变图像编码参数。
- 保存完整公开输入、原始图像、模型候选及真实反馈。当前 plan、末次动作
  回执与最新画面优先保留；历史以完整 assistant/tool 组竞争预算。累积的
  旧测量和检查点必要时移出工作上下文，原文仍可读。
- 旧工具历史另外压缩为 structured-public-memory-v1：最多 8 条动作回执、4 条测量、4 条其他反馈、4 条受阻后续记录；预算不足再移出较老条目。每条保留 source_turn、观察/请求编号、参数、结果、实测夹爪/位姿、错误及重复次数。不同结果不合并；原始事实仍在缓存。完整当前 plan 及未决问题直接保留，不从压缩结果自动写任务完成，不总结私有思考，不调用额外压缩模型。
- 示范帧按首尾和递归中点顺序选入剩余预算；其 CV 原记录随对应像素交付。
  未选帧只列可读缓存索引，不冒充已看过图片。过往当前帧明确标为历史。
- 沿用 session_context 的 list/read/crop。read 按 start/limit 分页返回精确
  JSON，每页最多两个 4,096 字符块；完整原图用 crop 和整幅尺寸读回。缓存
  有哈希与显式登记，不能读取其他会话、私有评分或给旧观察增加执行资格。
- 模型响应返回后核对实际 prompt usage；若超过保守估计，保留响应/usage
  并暂停，候选不派发。tokenize 的辅助 HTTP 请求不算模型生成调用。
