## 本轮发现与最小下一步

1. **保持与响应延迟必须分开测。** 抓起和移动过程中双指约 15 N 不代表长时间可靠保持；当前助手的 186 秒延迟构成明显混杂。下一步应先用既有控制器固定同一姿态/开度，测 holding 随时间的滑移；不要立刻靠扩大模型能力或修改摩擦参数掩盖问题。
2. **失败结束应独立于成功验收。** 增加明确的 unsuccessful/aborted 收尾语义即可，不需要为结束失败任务假装释放一次。成功路径继续保留撤离与稳定性检查。当前公共 finish_task 描述也应说明实际前置条件。
3. **几何候选必须醒目暴露适用假设。** grasp_target 已写明桌面支撑假设，但对高于桌面的目标仍返回可解 IK。至少应将该假设放到候选主要输出，避免把地面到顶面的高度当物体厚度；本轮不扩建三维系统。
4. **评分原因应准确区分失控掉落和缺失数据。** 保留失败结果，优先输出 uncontrolled release/grip lost，再列缺少哪个正常阶段快照。
5. **不要将自动写 plan 当作主动使用记忆。** 本轮实际根据掉落反馈改了 plan，也消费了新图；但没有主动历史检索，尚不能论证 session 缓存带来性能提升。
