## 非阻塞建议的处理

- **不增加 `max_dict_size` 参数。** 当前手动和模型入口的字典上限同为 500；现有共享函数已保留原边界。没有实际使用需求，不增加额外配置。
- **不保留可自动再次确认的失败提案。** 网络响应丢失可能已提交配置；继续要求重新读取实际策略，避免把“再次确认”当成自动重放。
- **不把缓存审批模式当作当前状态。** 操作员接口失败时明确返回失败，优于显示可能过期的模式。
- 空提案的错误提示、详细错误码及同批提案作废提示是可用性小项，不阻塞本次打包，未扩大实现范围。
- 已核对 `/tools TOOL`、`--root` 均有实际入口；成功 `/mode` 切换会清空旧配置提案。协议动作的会话、身份及审批绑定不在本轮改动范围。
- 原有大小边界、错误路径与工具调用由回归及仿真验证补充；不采纳仅为形式统一而添加参数、拆包、策略插件或 dev/prod 分支的建议。
