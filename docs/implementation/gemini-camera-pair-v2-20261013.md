# Gemini 相机对照 v2（2026-10-13）

范围限定为实验入口、计划传递与任务收尾评分。机器人、相机、计算后端与上一轮冻结源码逐文件相同。上一轮 job-01 和所有结果不修改。

## 输入与 plan

图片以会话内不可变的 frame-001.jpg 等短文件名直接放在公开目录，并给出可复制的完整 view_file 参数。像素 SHA256、来源/帧/时间保持；白名单不会接受目录外路径或改写后的像素。拒绝同名错误路径时只提示已批准的正确路径，不自动执行读取，也不新增免费模型修复轮次。

新响应格式为 content、plan、一个 tool_calls。plan 是至多 2000 字符的简短公开计划：初次恢复示范步骤，随后写观察进度、下一步与不确定性。它不含私有推理，不强制具体目标值或动作顺序。前端把模型原文写到现有 task_plan.interpretation，绑定真实 expected_version，下一轮自动读回真实版本。无需额外规划 API 调用，直接 task_plan 工具在此专用入口中隐藏，以免和自动写回竞争；公共 CLI/MCP 工具不变。

content 要求引用影响决策的图片 ID，并说明遮挡或没有新增信息。审查双相机时核对原始看图回执、原始公开判断、几何查询所用 observation_id 和后续动作；模型自述不是因果证据。

## 收尾

finish_task 前必须有实际张开夹爪后的成功撤离，当前 TCP 相对释放点距离至少 0.03 m，夹爪仍打开。路径由模型根据反馈选择，入口不替它生成撤离动作，也不证明路径安全。

模型结束后，执行器关闭前私下取三次状态，仿真时间跨度至少 2 秒、epoch 一致。评分端在模型会话关闭后检查：
- 同一目标的关系仍成立；
- 每次采样均无任何机器人几何接触，包括单指（本冻结 Piper 场景命名）；
- 三次样本间最大位移不超过 2 mm，最大姿态变化不超过 2°，速度不超过 5 mm/s。

这些是本次仿真短时采样判据，不代表连续无碰撞、无限期稳定或真实毫米级精度。分别报告 target_relations_success、retreat_verified、stable_after_retreat、normal_finish 和 task_complete。完整完成还要求会话正常结束并释放资源。

## 固定实验与异常

同一 level1_4_blockmanipulation_3 complex 示范、同一带腕部相机的场景、同一 gemini-3.8-flash-high。单固定相机与固定+腕部相机各一个全新会话，plan/skill 都开启；双相机顺序采集。顺序种子 20261013。两组接口完全一致，只有相机可见性不同。

预算沿用 80 外层调用、120 模型工具、65,536 累计输出（含思考）、1,800 秒新调用启动预算、300 秒单次等待。所有内部模型调用与失败回执计账；CLI 不支持服务端硬输出上限，超额回执不得派发。

已明确未执行的缺图/格式/预算响应计为该组模型响应失败，释放资源后允许下一组正常开始，不重跑失败组。连接/用量/计划持久化异常及清理失败仍暂停。原始提示、看图日志、模型计划、状态、动作及评分完整保留。仅两轮个案，不估计统计显著性；两组 plan 都开启，不能据此单独证明 plan 的因果收益。
