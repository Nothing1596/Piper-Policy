# 相机行为探索 v3

复用 v2 同一 complex 示范、场景、模型请求别名 gemini-3.8-flash-high、单固定相机与固定+腕部两会话。旧结果不改写。此次为用户授权的开放预算探索，不是等预算或无 plan 消融。

仅修改实验层：
- 公开接触反馈在模型请求前、响应返回后、每个运动下发前检查。夹持/未夹持发生转换时，返回新图、清除丢失抓取对应的历史偏移/计算缓存，向模型报告旧动作未执行；下一次模型响应写回新 plan。既不生成恢复轨迹，也不把私有物体身份交给模型。
- 模型响应允许多工具，工具名覆盖当前仿真 CLI 全集并保留已有几何助手。只读调用并发，状态变更协调，停止不等待动作锁。依赖前一操作的新观察或新版本不能凭假设填写；无效依赖由既有接口明确返回。
- 不设置累计 completion、工具次数、轮数、新调用启动时限和 agy 等待时限。正常任务完成或基础设施异常结束；真实用量和拒绝继续记录。执行器和网络请求的故障超时仍保留，不能无期限占据未知机器人状态。
- 原有图像读取隔离保留，避免读取 GT/其他会话；这是实验数据隔离，不是限制 Piper CLI 工具。原公共 CLI、求解器、执行器、审批和限位未改动。

验证重点：模拟模型思考期间的接触丢失后，旧动作和旧计划不提交，新画面进入下一请求且新 plan 写回；并发读实际重叠；超旧 token 上限仍保留并执行合法响应；旧入口回归通过。原生 MuJoCo 验收核对全部工具名、公开接触数据、双相机采集、计划读写和退出清理。

本轮观察记录：是否主动并发、接触变化触发次数、被退回的旧决策、plan 更新、图像引用、实际动作/成功关系/撤离稳定、全部 token 和时长。不能把此探索与旧固定预算直接合并计算方法提升。
