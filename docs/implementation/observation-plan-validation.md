## 重点回归

- 单/双相机真实子进程复用；顺序显式启动仍不超总预算；取消启动/观察、EOF/退出回收。
- 返回全图和 ROI；双相机的最新图均进入最多六张图的模型预算。
- 零畸变深度反投影、固定/腕部变换、已知平面/距离、无效深度、跨相机标定与错误路径。
- batch 内容与 NPZ 哈希一致性；相同 recipe 重复可读，冲突与撕裂写入拒绝。
- 旧批准/动作 idempotent 回放不重复使计划过期；新动作最终结束后刷新答案状态。
- 取图期间改问题、计算期间改计划、外部 query 缺少/过期 expected_version 都不覆盖新问题。
- unavailable 新结果清除旧测量；更改目标使旧答案过期；非当前任务必须显式 resume 后才能写入。
- 存储点/平面重复使用时重验标定和连接身份；相机光学坐标不能跨未知相机姿态测距。
- 原路径替换标定后，读取计划将已答测量标为过期；缺少观测来源的旧结果明确要求重新采样。
- 示范概览保留首尾，阶段分页保留 evidence_refs；快速视觉子集不隐藏执行模型可读的原图。
- 相同视频内容和检测器配置复用全视频 CV 分析，选定区间的评价仍有独立范围。

## 使用与后续

参见 [完整操作演示](../ROBOT-OBSERVATION-PLAN.zh.md)。一个 profile 只有一个当前任务指针；
新建任务保留旧任务文件以供恢复，不自动删除。旧任务的 `state=active` 表示未作废；
能否写入还须检查它是否为当前选中任务，不能凭这个字段绕过选择。

Kimi 最终审查的四项意见已逐项处理：标定原路径修改的失效检查和缺少来源的错误提示已修复；
距离结果已独立落盘并保存 evidence 引用。关于 resume 的意见采用上述显式恢复语义，
不增加另一套操作员确认；切换后晚到结果仍被当前任务及版本检查拒绝。

目前返回的是可审计的几何测量，不是抓取点正确性、接触、插入或无碰撞证明。
下一次实机测试需登记真实外参，先用已知尺寸物体核对固定/腕部变换与双视角测距，再比较
仅视频、视频+观察计划、视频+观察计划+几何后端的任务表现。软件通过不等于证明视频引导改进有效。
