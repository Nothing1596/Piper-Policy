# 2026-10-15：仿真接触参数修订

## 原因与边界

已有 Argon 实验发生定姿夹持时缓慢下滑。独立诊断中，双指接触法向力持续存在，摩擦系数翻倍仍在约 44 秒后掉落；只提高 MuJoCo 接触求解器的摩擦/法向约束阻抗比 `impratio`，下滑明显减少。这支持软接触求解引起持续蠕滑的解释，不能推出此前每一次失败都由物理参数造成。

本次仅修订未启动的实验。原始回合、用量、失败与中断日志、冻结源码和原场景均不改写，不追认旧实验为成功。

## 独立物理验证

使用此前记录的三种夹持姿态重建独立 MuJoCo 实例，初速度置零，夹爪保持关闭目标。每种参数各一次，持续 **240 秒模拟时间**，随后 J1 以约 1°/s 做 5° 往返并松爪。不是原始动态检查点的精确重放，也不是模型任务成功率。

| 物体 | 旧参数失去接触时刻 | 新参数 240 秒相对 TCP 下滑 | 新参数移动 / 松爪 |
|---|---:|---:|---|
| 玉米 | 44.0 s | 0.903 mm | 保持双指接触 / 正常释放 |
| 辣椒 | 57.0 s | 0.612 mm | 保持双指接触 / 正常释放 |
| 三角棱柱 | 24.5 s | 0.761 mm | 保持双指接触 / 正常释放 |

预先使用的检查条件：240 秒内不失去双指接触、相对下滑绝对值小于 2 mm、往返保持双指接触、松爪后无夹指接触、状态有限。新版本三例均通过。只支持这些姿态和时长下已复现问题得到抑制，不能保证任意抓法、加速度、对象或无限等待不掉落。抽屉等接触任务仍需实际任务结果验证。
