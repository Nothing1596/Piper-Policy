## 公共接口说明

各条件都明确：夹取物体使用 `set_gripper(completion="bilateral_contact")`；空夹爪宽度定位和张开释放使用 `completion="width"`。前者只证明双侧接触，随后必须查看提升与释放结果。适配器不改写模型参数，也不把超时转为成功。该说明独立于观察 skill，不能把它的效果归为 skill 或短调用策略。

截断响应不进入历史、不执行任何工具、不占用运动 request_id。截断用量仍进入费用账；新决策前获取新图。含工具调用的截断响应直接终止，不修复或执行半截参数。API/用量异常及已经执行的未知动作仍暂停，不自动重发。

短调用与额外行动引导组成一个策略，因此本轮评价它们的组合，不宣称单独识别 token 上限的作用；也不用于重新解释原八组的 skill 效应。
