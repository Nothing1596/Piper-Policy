# LongVIL 离线视频实验 v2

本轮估计“观察 skill 引导”和“在相同引导下持久化 plan”的作用。结果只涉及录制视频的动作语义和符号状态，不是 Piper 真机成功率。正式作业仅在开发验收、完整样本审核、用户分层抽查及费用预测都通过后启动。

## 固定条件

| 条件 | 模型可见引导 | 状态和工具 |
|---|---|---|
| A / baseline | 通用视频解释、程序语法、物体名单 | demo_watch；无持久化计划 |
| B / skill | A + 共享 observation skill 的离线部分 | 同 A |
| C / skill_plan | B + plan 持久化适配说明 | demo_watch、task_plan；前端预建任务并提供实际 ID/版本 |

B/C 的观察引导由同一 SKILL.md 渲染，B 是 C 的共享前缀。比较 B−A 估计问题/证据引导收益，C−B 估计持久化增量。A 同样可以内部规划，三组均调用 deepseek-flash/high/65536。保留 submit_program 输出字段及既有机器人原语名，没有新增运动接口。

内置模型入口仍默认关闭 DeepSeek thinking、输出 2048 token。此次实验通过外部 API→真实 CLI/MCP 执行，不能将它的结果解释成内置默认配置效果。MCP 只给 actor 提供当前演示的 demo_watch 和 C 组的 task_plan，没有机器人动作、评分或任意文件访问工具。

## 图像与视觉评价

每视频固定均匀选最多12帧，包含首末帧，首帧同时作为录制初态，仅显示一次。每张图片有视频 SHA、帧 ID、实际 PTS 时间和 recorded/NOT live 标签。元数据数量和图片数量不匹配则失败。后续保留初始概览和最近两组补看，每个 API 请求最多36张图片；事件日志记录真正发送的数量。images_sent 是累积新加入的工具图片块，不是独立观察次数，不能拿它推断每次请求的图片数。

共用 CV/YOLO 评价，权重保持 yolo11n。模型优先核对原图；检测类别和快速视觉评价都是可反驳假设。离线 workflow 不请求不存在的实时相机或3D测量。视觉问题的解释及引用保存在 interpretation，已澄清问题从待决列表移除，不要求伪造后端测量状态。

小消融只对同一概览调用一次 deepseek-flash/low/4096，冻结结果跨三组共享。提示只提取首末可见状态、空间歧义，不重构完整动作答案；后续补看不追加低模型调用。未知/虚构引用、结构错误仍拒绝。引用集合可按真实时间确定性排序，保留原始响应、排序前后清单，阶段顺序不变。正式快速评价不可用时保存并暂停，不能把无评价输入标成启用组。

## 样本与评分

LongVILBench 固定 revision `59f002209575ae1b3e619a2ffd5a831a15194c2a`。种子20261010，3难度×3类别，每层3个未评测新任务；候选/替补顺序固定，排除已查看的开发视频和旧抽屉示范。27对 clean/complex 样本逐段审核，审核材料每视频含48张实际时间帧；审核对象、主要关系和顺序，不声称证明全部接触或物理稳定性。疑点不修改官方GT，按同层固定替补顺序处理。

模型只收到物体名单、视频、公共程序规则。官方 code/action_sequences/positions/horizon 留在私有评分侧。正式GT须通过严格解析和原始评分器自检。place 的参数是放置参照物，例如 pick(corn);place(eggplant,behind) 表示拿玉米放到茄子后方，不表示拿起茄子。审核页用中文成对动作展示，原语标签作为可展开来源。

主要指标：严格 AST 解析后动作、操作对象、参考对象、关系和顺序完全一致率。变量改名和重复getpos不影响语义；非法语句、未配对pick/place、未知对象/关系不能被静默忽略。并列报告原始 EMA/SMS/FSA、语义步骤匹配、遗漏、多余、空间错误和顺序错误。符号执行超时/非法生成程序按失败；基础设施故障不当模型失败，暂停且保留记录。

主实验324轮：27×2视频×3条件×2重复。小消融54轮：预选9任务×2视频×3条件×1重复；固定对照为对应主实验repeat=0。主实验结束后再做小消融。区组内随机条件顺序，全部会话独立。主比较按27个语义任务整体重采样，保留视频/重复/条件，5000次 bootstrap，两个比较分别给出97.5%区间。54轮消融仅报告配对改善/退化和费用，不做显著性结论。

## 作业与费用

工具：run_longvil_v2.py 执行；longvil_dataset.py 下载并准备审核；longvil_metrics.py 解析/语义比较；longvil_budget.py 计费；build_longvil_v2_job.py 校验、冻结和可选提交。

每轮上限30次 actor API、60次工具尝试（包括语法错误尝试）、900秒新调用启动预算。握手、列工具、固定初始概览、C的预建任务和程序验收读计划单独记录，不作为模型决策调用。无自动重试；续跑需显式 --resume，已评分失败也不重跑。原始attempt日志只追加；代码、提示、排程、manifest、评分器或权重改变会拒绝续跑。

全部DeepSeek调用进入共享CNY账本，包括失败的开发视觉调用。非高峰每百万缓存命中/未命中/输出 `.02/1/4` 元，高峰加倍；跨高峰按高价计。费用上限75元，累计估算≥72元停止发起新请求，保留单个串行在途调用3元余量。usage缺失保守记3元并暂停，不能不记账继续。账本文件锁禁止两个本地作业并发使用同一余额。

冻结包含代码、skill、提示、数据名单与独立视频/GT副本、官方评分器、检测器、价格配置和排程；启动前核对文件SHA。密钥仍由既有本机私有启动器读入子进程环境，产物不存密钥。供应商实际权重无法冻结，逐请求记录请求配置、返回model别名和时间。

提交后后台单进程顺序执行，生成逐轮事件、输入审核、CSV、费用账、配对统计和RESULTS.md；异常保存checkpoint，监督进程只等待并保存退出状态，不重启。按用户要求提交后不建立监视任务。

## 证据边界

开发使用3段已看过的clean视频，9个A/B/C回合及3个C快速评价回合；修复前后回合均保留，费用累计，成绩不进入正式结果。允许的一次局部提示修正已记录在prompt-revision.json；随后仅修复引用集合的确定性排序与预算/提交边界，不按成绩择优调提示。

Mac 本地软件测试、真实外部 API 与 CLI/MCP 开发验收、数据审核、正式作业提交/完成分别记录。没有本轮Windows、ROS或真实机械臂验收。
