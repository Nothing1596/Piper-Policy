## 用途与当前身份

这条分支用于溯源迭代思路，不是单独产品发行版。截至 2026-10-21，远端和本地分支都停在 `9f12a69604d71c461dfb78d5319bc51b0b1bfb57`，最后一项为失败任务正常收尾，记录日期为 2026-10-14。它包含 27 个重新整理的提交，保留必要代码、剔除模型/网格等大资产及多数文档。

它现在落后 main@09256a5，不能说“最新和 main 一致”。例如 main 已有的 behavior_monitor、后续几何/反馈修订、视频序列复核和远端视频经验实验在该分支缺失或仍是旧实现。两条历史不是简单的同一祖先演进，不能用“落后几个提交”概括全部差异。

## 怎样阅读而不影响当前工作树

不切换、不重置现有 main，直接在仓库根目录使用只读 Git 命令：

```sh
git log --reverse --oneline experiment/derivation
git show --stat 9f12a69
git show 9f12a69 -- tools/run_longvil_online.py
git diff experiment/derivation main -- piperx-cli/src tools
```

查看一段实现时，先看提交说明的原因，再对照对应测试和下一个修订；不要把每个历史中间态都当作当前可部署版。想运行程序请使用完整 main 或正式包，不从这条精简分支直接构建需要缺失 MuJoCo 网格的发行包。

## 与 main 同步的边界

如果以后同步，应继续按实验发现拆分有原因的提交，保留精简资产规则并核对源码差异；不能用一次覆盖提交伪造中间演绎。本轮只新增 main 工作区的说明，没有改这条分支、推送或宣称其已经同步。
